# POS ฉุกเฉิน — ร้านอึ้งลักเส็ง

โปรแกรมขายสำรองตอน Sea & Hill POS ใช้ไม่ได้ ขายต่อได้ พิมพ์ใบเสร็จได้ แล้วค่อยส่งบิลเข้า POS หลักทีหลัง

## ติดตั้ง

1. เปิดไฟล์ `emergency-pos-setup-X.Y.Z.exe` (ดาวน์โหลดจากหน้า Releases ของ GitHub) กด "ใช่" ที่หน้าต่างขอสิทธิ์ผู้ดูแล
2. ติดตั้งเสร็จแล้วเปิดจากไอคอน **POS ฉุกเฉิน** บนเดสก์ท็อป เปิดได้ครั้งละหน้าต่างเดียว
3. ครั้งแรก: ตั้งค่า → ใส่ **รหัสเครื่อง** (POS01 / POS02), **รายชื่อพนักงาน**, **URL รายการสินค้า** (ลิงก์ Google Sheet แบบ CSV) และเลือก **เครื่องพิมพ์ใบเสร็จ**
4. เครื่องที่สองติดตั้งจากไฟล์เดียวกัน แต่ใส่รหัสเครื่องคนละค่า

โปรแกรมอัปเดตตัวเองจาก GitHub ขึ้นแบนเนอร์ "มีโปรแกรมเวอร์ชันใหม่" กด **อัปเดตเลย** ตอนไม่มีสินค้าค้างในบิล

## ใช้งานประจำวัน

| ทำอะไร | ทำอย่างไร |
|---|---|
| ขาย | เลือกชื่อพนักงาน → ยิงบาร์โค้ด (หรือพิมพ์ชื่อสินค้า) → **F11 รับเงิน** → เงินสด / โอน / โครงการรัฐ → พิมพ์ใบเสร็จ |
| สินค้าที่ไม่มีในรายการ | ยิงแล้วขึ้น "ไม่พบสินค้านี้ในรายการ" → ใส่ชื่อกับราคาเอง (บิลจะมีป้าย "มีรายการคีย์เอง") |
| ส่งบิลเข้า POS หลัก | **บิลค้างส่ง** → ส่งเข้า POS หลัก ตามขั้นตอนบนหน้าจอ (เปิดบิลใหม่ใน Sea & Hill, คลิกช่องยิงบาร์โค้ด, ห้ามแตะเมาส์/คีย์บอร์ด) |
| เทียบยอด | หลังส่งครบ หน้าต่างเทียบยอดโผล่มุมขวาบน เทียบกับ Total ของ POS หลัก แล้วกด **ยอดตรง รับเงินแล้ว** หรือ **ยอดไม่ตรง** |
| ยกเลิกบิล | บิลค้างส่ง → ยกเลิกบิล (ต้องใส่เหตุผล บิลไม่ถูกลบ ดูได้ในแท็บ "ยกเลิก") |
| ปิดร้าน | **สรุปยอด** → เลือกวัน → **พิมพ์ใบสรุป** (เงินสดสุทธิ = เงินสดที่รับ − เงินทอน ตรงกับเงินในลิ้นชัก) |

ถ้าระหว่างส่งเข้า POS หลักแล้วคีย์บอร์ด/เมาส์ค้าง ให้กด **Ctrl+Alt+Del** แล้วยกเลิก ระบบจะปลดล็อกเอง

## ย้ายบิลไปส่งจากอีกเครื่อง

เครื่องต้นทาง: บิลค้างส่ง → **ส่งออกบิลค้างส่ง** → เก็บเป็นไฟล์ `.json` (ลง USB หรือส่ง LINE ให้ตัวเอง)
เครื่องปลายทาง: บิลค้างส่ง → **นำเข้าบิลจากอีกเครื่อง** → เลือกไฟล์

- บิลที่นำเข้าจะมีป้าย "มาจากเครื่อง POS01 #3" และรหัสเครื่องเดิม
- นำเข้าซ้ำได้ ไม่เกิดบิลซ้ำ (ระบบข้ามบิลที่มีแล้ว)
- ไฟล์เสียหรือไม่ใช่ไฟล์บิล: ไม่นำเข้าอะไรเลย ข้อมูลเดิมไม่ถูกแตะ
- หลังนำเข้าแล้ว ควรส่งบิลเข้า POS หลักที่เครื่องปลายทางเท่านั้น และไม่ต้องส่งซ้ำที่เครื่องต้นทาง

## ข้อมูลอยู่ที่ไหน

ตั้งค่า → **เปิดโฟลเดอร์ข้อมูล** — `bills/` (บิลรายวัน), `backup/` (สำรองทุก 30 นาที เก็บ 30 วัน), `settings.json`
ถ้าไฟล์บิลวันไหนเสีย โปรแกรมกู้จากไฟล์สำรองให้เอง และขึ้นคำเตือนที่แถบสถานะ

## สำหรับผู้พัฒนา

```
npm test              # เทสต์ทั้งหมด
npm run harness:ui    # ดูหน้าจอในเบราว์เซอร์ด้วยข้อมูลจำลอง (ไม่เปิด Electron)
npx electron-builder --win --publish never --config.directories.output=dist/vX.Y.Z
```

ห้ามรัน `npx electron .` จากซอร์สโดยตรง (ดู `DESIGN.md` และ `PRODUCT.md` สำหรับแนวทางออกแบบ)
